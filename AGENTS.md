# Repository instructions

This is a public starter and Skill, not a live personal memory store.

- Repository work may update public documentation, templates and the Skill.
- Use synthetic examples. Keep personal profiles, private conversations, credentials, host-specific paths and real project state outside this checkout.
- Preserve the lightweight workflow: task-scoped retrieval, direct project maintenance, evidence-based correction, proposals only for unresolved coordination.
- The portable Skill is at [skills/shared-vault/SKILL.md](skills/shared-vault/SKILL.md). For the starter workflow read [vault/00_Home/WORKFLOW.md](vault/00_Home/WORKFLOW.md) when changing behavior.
- Update affected links and examples when changing a path. Check the final diff and publication scope.
- The file allowlist in .gitignore helps review changes; it is not a security boundary. Review every staged file before publishing.
