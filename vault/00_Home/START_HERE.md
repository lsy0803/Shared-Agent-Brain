# 从这里开始

这是空白模板，不包含真实个人资料。实际使用请先复制到私人目录，并向 Agent 指定该目录。

| 需要什么 | 去哪里 |
| --- | --- |
| 开始或续接项目 | [项目索引](../02_Projects/PROJECTS.md) |
| 用户确认的背景与偏好 | [PROFILE](PROFILE.md) |
| 长期负责的领域 | [领域入口](../03_Areas/AREAS.md) |
| 可复用、已验证的经验 | [LESSONS](../04_Resources/LESSONS.md) |
| 待处理材料与争议 | [INBOX](../01_Inbox/INBOX.md) |
| 协作权限、纠错和并发 | [WORKFLOW](WORKFLOW.md) |
| 自动记录与敏感边界 | [RECORDING](RECORDING.md) |

普通任务只打开相关入口；有项目当前状态时直接使用它，不需要每次从本页读完所有链接。
