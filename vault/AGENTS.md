# 私人 Vault 的 Agent 入口

此文件夹在复制到私人目录后，可作为多 Agent 共同维护的知识库。公开仓库中的副本只作空白模板，不写入真实个人记录。

使用前由用户明确实际路径和准许的 Agent。获准 Agent 可以直接贡献与维护自己的任务，无需固定交给另一 Agent 审批。既有宿主和用户规则优先。

## 按任务读取

- 入口不明时看 [START_HERE](00_Home/START_HERE.md)；已知项目就直接查项目当前状态。
- 个人背景会影响方案时查 [PROFILE](00_Home/PROFILE.md) 的相关条目。
- 技术选型、旧问题或复用经验时搜索 [LESSONS](04_Resources/LESSONS.md)。
- 不例行全文加载画像、日志和其他项目。已读且未变的上下文可以复用。
- 直接修改前读目标当前正文，保留别人有效与无关的内容。

工作流或争议处理需要时读 [WORKFLOW](00_Home/WORKFLOW.md)。准备长期记录时读 [RECORDING](00_Home/RECORDING.md)。

重要更新注明实际 Agent、日期、来源和范围。证据不足时标未知或争议；不能把其他 Agent 的推断当事实。写后检查并给简短回执。

同一文件同时安排一个写入者；发现版本变化或另一 Agent 在写时先协调。此规则不实现操作系统文件锁。
